# Kết quả thực nghiệm

Không commit prediction thô hoặc dataset lớn. Commit được các bảng CSV đã tổng
hợp, hình biểu đồ và ảnh minh hoạ đã chọn. Số liệu tổng hợp cuối cùng dùng
`tables/final_metrics_template.csv`; giữ `experiment/metrics_iou_050.csv` làm
artefact tái lập của lần chạy.

Nếu chưa chạy Fiji hoặc chưa có dataset thực, để ô trống/`NA` và ghi rõ lý do.
Không thay bằng số liệu giả định hoặc số từ bài báo khác.
