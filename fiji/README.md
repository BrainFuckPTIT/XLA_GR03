# Fiji/ImageJ

Thư mục dành cho phần việc thành viên 3:

- `macros/`: ImageJ Macro;
- `scripts/`: Jython/Groovy script chạy batch;
- `workflows/`: hướng dẫn cài plugin và protocol kiểm chứng;
- `screenshots/`: ảnh giao diện cần dùng trong báo cáo.

Mọi lần chạy phải ghi model, probability threshold, overlap threshold,
normalization, số tile và phiên bản Fiji/StarDist.
